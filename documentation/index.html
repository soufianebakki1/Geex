Installation

To setup the Geex admin, follow below-mentioned steps

  • Visual Studio: Ensure you have Visual Studio installed on your machine.
  • Download Theme Files: Obtain the theme files required for your application.
  • Install Node.js: If not already installed, download and install Node.js
  • Install SASS Compiler: Open a command prompt and run the following command to install the SASS compiler globally.
    •                                         npm install -g sass
  • Compile SCSS to CSS: Run the following command in the command prompt to compile SCSS files to CSS
    •                                         sass Geex\wwwroot\sass:Geex\wwwroot\css
  • Open Visual Studio: Open the Geex.sln solution file in Visual Studio.
  • Run Application: Build and run your application in Visual Studio. You can do this by pressing F5 or selecting "Start Debugging" from the Debug menu.
  • View in Browser: Once the application is running, open your preferred web browser and navigate to the URL specified by Visual Studio, typically https://localhost:{port}.
